# Blazecoin Core V1.5 - Quick Start Guide

> **Note (corrected 2026-04-26):** This document was written during initial V1.5 planning, on the assumption that 0.8.6.2 (the production wallet) had a sync stall around block 2,000,000. Subsequent verification showed that 0.8.6.2 syncs the full ~4.1M-block chain without issue — the production node has been running continuously since 2014. The 2M-block stall was specific to the failed **V2.0** attempt (Bitcoin Core 28.0 base), which motivated V1.5's creation. V1.5's actual contributions are: modern toolchain compatibility (MSVC 2022 / OpenSSL 3.x / Boost 1.90), latent NDEBUG/assert bug fixes inherited from upstream, and proactive checkpoint + header-limit additions for future chain growth. The "2M sync wall" wording below should be read in that corrected context. See `Blazecoin_V1.5_Technical_Changelog.md` for the accurate post-build account.

## Step-by-Step Instructions

### Step 1: Extract Checkpoint Hashes (5 minutes)

1. **Ensure your production Blazecoin daemon is running and fully synced**
   ```powershell
   blazecoin-cli.exe -rpcport=55413 getblockcount
   ```

2. **Edit the PowerShell script** with your RPC credentials:
   - Open `Get-CheckpointHashes.ps1`
   - Update `$rpcUser` and `$rpcPassword` with your production daemon credentials

3. **Run the script:**
   ```powershell
   cd C:\path\to\source\repos\Blazecoin_Website_MVC_Microservices
   .\Get-CheckpointHashes.ps1
   ```

4. **Copy the output** - The script will generate C++ code and save it to `Blazecoin_V1.5_Checkpoints.txt`

### Step 2: Modify C++ Source Code (15 minutes)

1. **Navigate to the C++ wallet directory:**
   ```powershell
   cd C:\path\to\source\repos\Blazecoin_Core_V1.5
   ```

2. **Open `src/checkpoints.cpp` in your editor:**
   ```powershell
   code src/checkpoints.cpp  # If using VS Code
   # OR
   notepad src/checkpoints.cpp
   ```

3. **Replace the checkpoint map** with the code generated by the PowerShell script

4. **Update the checkpoint metadata** (CCheckpointData) with the timestamp from the script output

5. **Search for hardcoded limits:**
   ```powershell
   cd src
   Select-String -Pattern "2000000|MAX.*HEADER|MAX.*BLOCK.*HEIGHT" -Path *.h,*.cpp
   ```
   - If you find any limits around 2,000,000, change them to **50,000,000**

6. **Update the version number** in `src/clientversion.h`:
   ```cpp
   #define CLIENT_VERSION_MAJOR       1
   #define CLIENT_VERSION_MINOR       5  // Change from 8 to 5  // Change from 0 to 5
   ```

7. **Save all changes**

### Step 3: Compile the Wallet (30-60 minutes)

**Requirements:**
- Visual Studio 2019/2022 with C++ tools
- MinGW-w64 (alternative)
- Qt 4.8 or 5.x
- Boost, OpenSSL, Berkeley DB 4.8

**Using MinGW (Recommended for Windows):**
```powershell
cd C:\path\to\source\repos\Blazecoin_Core_V1.5
mingw32-make -f Makefile.mingw
```

**Note:** You may need to edit `Makefile.mingw` to set correct paths for dependencies.

**Expected Output:**
- `blazecoind.exe` - Daemon
- `blazecoin-cli.exe` - RPC client
- `blazecoin-qt.exe` - GUI (if built with Qt)

### Step 4: Test V1.5 in Isolated Environment (Hours/Days)

1. **Create test data directory:**
   ```powershell
   mkdir C:\blazecoin-data\BlazecoinV1.5
   ```

2. **Config file** is auto-created on first launch at `<datadir>/blazecoin.conf`,
   pre-seeded with two known-good `addnode=` peers and commented-out RPC
   placeholders. Edit it freely if you want to enable RPC, change ports, or
   add peers. A typical isolated-test conf looks like:
   ```ini
   rpcuser=blazecoin_v15_user
   rpcpassword=CHANGE_THIS_PASSWORD
   rpcport=55415
   port=55416
   txindex=1
   addnode=85.15.179.171:55414
   addnode=91.206.16.214:55414
   ```

3. **Start V1.5 daemon:**
   ```powershell
   cd C:\path\to\source\repos\Blazecoin_Core_V1.5
   .\blazecoind.exe -conf=C:\blazecoin-data\BlazecoinV1.5\blazecoin.conf -daemon
   ```

4. **Monitor sync progress:**
   ```powershell
   .\blazecoin-cli.exe -rpcport=55415 getinfo
   .\blazecoin-cli.exe -rpcport=55415 getblockcount
   ```

5. **KEY MILESTONE:** Watch for sync to pass **2,000,000 blocks** - this confirms the fix works!

## Troubleshooting

### Script Can't Connect to Daemon
- Verify daemon is running: `blazecoin-cli.exe getinfo`
- Check RPC port is correct (default: 55413)
- Verify RPC username/password in script

### Compilation Fails
- Install all dependencies (Qt, Boost, OpenSSL, BerkeleyDB)
- Check library paths in Makefile
- Review error messages carefully
- Search for similar errors in Bitcoin/Litecoin forums

### Sync Stops at Same Height Again
- Check `debug.log` in data directory
- Verify checkpoint hashes are correct
- Ensure you increased all hardcoded limits
- Compare block hash with production to confirm chain validity

### Need Help?
- Review full guide: `Blazecoin_V1.5_Upgrade_Guide.md`
- Check Bitcoin Core build documentation
- Review Litecoin compilation guides (very similar)
